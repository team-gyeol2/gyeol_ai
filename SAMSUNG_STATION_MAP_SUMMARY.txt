  자유 공간 셀: 2,229개 (89.2%)
  최대 연속 안전 영역: 2,213 셀 (22,130,000m² = 22.13km²)

================================================================================
좌표 체계
================================================================================

격자 좌표계:
  원점: 남서쪽 모서리 [0, 0]
  행(i): 남쪽(0) → 북쪽(49)
  열(j): 서쪽(0) → 동쪽(49)
  
  예시:
  [0, 0]   = 37.035528°N, 127.032842°E (남서 모서리)
  [25, 25] = 37.058050°N, 127.061064°E (중앙/삼성역)
  [49, 49] = 37.079672°N, 127.088158°E (북동 모서리)

좌표 변환 공식:
  격자 → 위도: lat = south + (i + 0.5) * (north - south) / 50
  격자 → 경도: lon = west + (j + 0.5) * (east - west) / 50
  
  위도 → 격자: i = (lat - south) / (north - south) * 50
  경도 → 격자: j = (lon - west) / (east - west) * 50

거리 변환:
  1셀 = 100m × 100m
  경로 길이(셀) × 100 = 실제 거리(m)
  예: 50셀 경로 = 5,000m = 5km

시간 변환 (드론 속도 15m/s 기준):
  거리(m) / 15 = 비행시간(초)
  예: 5,000m / 15 = 333초 ≈ 5.5분

================================================================================
제한 사항
================================================================================

⚠ 주의사항:

1. 데이터 정확도
   - OSM은 크라우드소싱이므로 100% 정확하지 않음
   - 연 1~2회 업데이트됨
   - 최대 ±2-10m 오차 가능

2. 격자 해상도
   - 100m × 100m 셀로는 작은 장애물 놓칠 수 있음
   - 세부 지형 정보 부재
   - 건물 높이 정보 없음

3. 실제 비행
   - 이 맵만으로는 실제 비행에 부족함
   - 추가 센서 데이터 필요 (LIDAR, 카메라 등)
   - 날씨, 풍속 등 고려 필요

4. 도시 환경
   - 고층 건물 많음 (GPS 신호 약화)
   - 전자기 간섭 있을 수 있음
   - 규정상 비행 제한 지역
